A cozy single-file island life game that runs in your browser. Click **PLAY** above to launch it — no install needed.

Plant crops, fish, craft, visit neighbors, and grow your little getaway.

## Controls
- On-screen joystick + **A** button (touch and mouse)
- Map, craft, pets, and more from the HUD buttons

## Files
- `index.html` — the whole game. GitHub Pages serves it at the PLAY link above.
